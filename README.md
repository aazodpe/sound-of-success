# The Sound of Success

Portfolio project for **CSCI 5612 &mdash; Machine Learning**, University of Colorado Boulder.
Atharva Zodpe.

**Live site:** https://aazodpe.github.io/sound-of-success/

What popular music is actually made of, and whether a song's success can be seen in the
music itself.

## Repository layout

```
docs/          the project website (GitHub Pages serves from here)
  content/     page content fragments; edit these, then run build_site.py
  images/      every figure and data preview, generated by the scripts
  build_site.py
code/          the analysis, numbered in the order it runs
data/
  raw/         exactly as downloaded or returned by the APIs, unmodified
  clean/       the output of the preparation scripts, plus one metrics
               JSON per module holding every number quoted on the site
```

## Reproducing

```bash
cd code
python 01_collect_api_data.py     # ~30 min; no API key needed
for f in 0[2-8]_*.py 09_*.py 1[0-9]_*.py; do python "$f"; done
cd ../docs && python build_site.py
```

The scripts are numbered in dependency order, so running them in sequence is enough.
Every model uses a fixed seed (5612), so the numbers quoted on the site reproduce exactly.

Requires Python 3 with `pandas`, `numpy`, `matplotlib`, `scipy`, `scikit-learn` and
`xgboost`. The collection script uses only the standard library.
