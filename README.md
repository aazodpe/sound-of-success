# The Sound of Success

Portfolio project for **CSCI 5612 &mdash; Machine Learning**, University of Colorado Boulder.
Atharva Zodpe.

**Live site:** https://aazodpe.github.io/sound-of-success/

What popular music is actually made of, and whether a song's success can be seen in the
music itself.

## Repository layout

```
docs/          the project website (GitHub Pages serves from here)
  content/     page content fragments; edit these, then run build_site.py
  images/      every figure and data preview, generated by the scripts
  build_site.py
code/
  01_collect_api_data.py    gathers data from the Deezer and MusicBrainz APIs
  02_clean_data.py          cleans and prepares every dataset
  03_eda_visualizations.py  produces the exploratory figures
  04_data_previews.py       renders the raw/clean before-and-after tables
data/
  raw/         exactly as downloaded or returned by the APIs, unmodified
  clean/       the output of 02_clean_data.py, with zero missing values
```

## Reproducing

```bash
cd code
python 01_collect_api_data.py     # ~30 min; no API key needed
python 02_clean_data.py
python 03_eda_visualizations.py
python 04_data_previews.py
cd ../docs && python build_site.py
```

Requires Python 3 with `pandas`, `numpy` and `matplotlib`. The collection script uses only
the standard library.

## Data sources

| Source | Access | Link |
|---|---|---|
| Spotify audio features (32,833 tracks) | Downloaded CSV | [TidyTuesday 2020-01-21](https://github.com/rfordatascience/tidytuesday/tree/master/data/2020/2020-01-21) |
| Billboard Hot 100, 1958&ndash;2026 | Downloaded CSV | [utdata/rwd-billboard-data](https://github.com/utdata/rwd-billboard-data) |
| Deezer tracks and artists | Public API, no key | [developers.deezer.com/api](https://developers.deezer.com/api) |
| MusicBrainz listener tags | Public API, no key | [musicbrainz.org/doc/MusicBrainz_API](https://musicbrainz.org/doc/MusicBrainz_API) |
