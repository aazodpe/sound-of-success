NaiveBayes

Overview

Naïve Bayes estimates how likely each possible label is given what it observes, assuming each piece of evidence contributes independently. That assumption is usually wrong in detail, but it makes the method fast and surprisingly hard to beat, particularly on text.

Two uses are planned. On the numeric side, predicting a song's genre from its discretized audio qualities. On the text side, using the free-text tags listeners write about artists to predict genre or era — a natural fit, since Naïve Bayes was built for exactly this kind of word-count data.
