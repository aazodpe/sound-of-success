SVMs

Overview

A support vector machine looks for the boundary that separates two groups with the widest possible margin, and its kernel trick lets that boundary bend into shapes a straight line could never make.

Where a decision tree carves the song space into rectangles, an SVM can draw curved borders through it. Linear, polynomial and radial basis function kernels will be compared on the same classification task, which shows directly how much of the structure in the data is genuinely non-linear.
