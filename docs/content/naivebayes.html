Naïve Bayes

Clustering and PCA both failed to find genre in the sound, but neither was ever told what a genre is. Supervised learning changes the terms: the model is shown thousands of labelled examples first. This tab asks whether being given the answers to study makes the pattern findable — and whether the same help works on the harder question of what charts.

Overview

Naïve Bayes is a classifier built directly on Bayes' theorem. Given a song, it asks how likely each possible label is in light of what it observes, and picks the label with the highest answer. To get there it needs two ingredients from the training data: how common each label is to begin with, and how typical each measured value is within each label. A song that is loud, fast and barely acoustic is evaluated against every genre in turn, and the genre under which that combination looks least surprising wins.

The word "naïve" refers to the assumption that makes the arithmetic tractable: every feature is treated as independent of every other, given the label. That is plainly false here — loudness and energy correlate at 0.69, as the exploration showed — and the model will effectively count that shared information twice. The surprise of Naïve Bayes is that it often classifies well anyway, because picking the largest probability does not require the probabilities themselves to be right, only for the correct label to come out ahead. Its other strengths are practical: it trains in a single pass over the data, needs relatively few examples per class, and has no parameters to tune. This makes it a sensible first supervised method and a useful yardstick — whatever it achieves is roughly the floor that more elaborate methods should clear.

There is not one Naïve Bayes but a family, and the members differ in what they assume a feature fundamentally is. Multinomial Naïve Bayes, the standard variant and the one this assignment requires, treats each feature as a non-negative count or weight, as though every value were a tally of how many times something occurred. It was designed for text, where the features are word counts in a document, and it cannot accept negative numbers at all. Bernoulli Naïve Bayes instead treats every feature as a yes-or-no flag: not how much of something there is, but whether it is there. On text it models whether a word appears in a document rather than how often, and its distinguishing property is that it explicitly uses the absence of a feature as evidence, which Multinomial simply passes over. A third member, Gaussian Naïve Bayes, assumes each feature follows a bell curve with its own mean and spread within each class, which makes it the natural fit for continuous measurements like the ones in this project.

What this is being used for here is a direct follow-up to Module 2. The clustering found almost no correspondence between the sound of a song and its genre, scoring 0.020 on the adjusted Rand index. But clustering was working blind. If genre information exists in these ten numbers at all, a supervised method given twenty thousand labelled examples should be able to extract at least some of it, and the amount it manages is a far better measure of how much genre is really there. The same approach is then turned on the question the project actually cares about: whether a song reached the Billboard Hot 100.

Data Prep

Supervised learning imposes two requirements that the unsupervised methods did not. The first is labels. Every row must carry the answer being predicted, which means only labelled data can be used at all — the model learns by comparing its guesses against known outcomes, and a row without an outcome teaches it nothing. Two labels were available in the cleaned data: the genre each song was catalogued under, and whether it ever appeared on the Hot 100. Both were used, as separate prediction tasks.

The second requirement is a split. A model scored on the same songs it was built from will flatter itself, because it can succeed by memorising rather than generalising. The data was therefore divided into a training set of 20,653 songs, from which the models are built, and a test set of 5,164 songs, which is held back and used only once the model is finished. The split is stratified, meaning each class appears in the same proportion in both halves, so the test set is not accidentally harder or easier than the training set. Crucially the two sets are disjoint: no song appears in both. This is not a formality. If even a fraction of the test songs had been seen during training, the reported accuracy would partly measure recall of specific songs rather than any learned pattern, and the number would be meaningless. The split script asserts disjointness rather than assuming it.

One further step was needed for the required model. Multinomial Naïve Bayes cannot accept negative values, and loudness is measured in negative decibels while the standardised features used in Module 2 are centred on zero. Every feature was therefore rescaled into the range zero to one. The scaler was fitted on the training data only and then applied to the test data; fitting it across everything would let the minimum and maximum of the held-out songs influence the model, which is a subtle form of the same leakage the split exists to prevent. For Bernoulli Naïve Bayes, which needs present-or-absent inputs, each feature was instead reduced to whether it sits above its training-set median.

Results

Accuracy on its own is a treacherous measure, so it is reported here against the only honest reference point: the accuracy of a model that ignores the song entirely and always guesses the commonest answer. For genre that baseline is 19.1%, because rap is the largest of six roughly balanced classes. For charting it is 86.8%, because only 13.2% of songs ever charted — and that high number is exactly why accuracy alone cannot be trusted on this task.

The ordering on genre is not arbitrary. Multinomial performs worst because its core assumption is wrong for this data: it reads danceability of 0.7 as though it were a count of seven occurrences of something, when the value is really a position on a scale. Bernoulli does better by throwing away the magnitudes and keeping only "above typical or not", which is a cruder description but a less mistaken one. Gaussian does best because its assumption is the one that actually matches — these are continuous measurements that really do cluster around different averages in different genres. Fitting all three turns the textbook distinction between them into something measurable.

Conclusions

The genre result is the one that changes the project's story. Module 2 concluded that genre was not present in the sound, on the evidence that clustering recovered it at 0.020 out of 1. That conclusion now needs qualifying. Given labelled examples to learn from, Naïve Bayes identifies genre at more than twice the rate of guessing — 44.2% against 19.1% for the best variant. So the information is in the audio measurements. What Module 2 really established is subtler and more interesting: genre is not the dominant structure in the data, so a method looking for the strongest pattern will find production intensity instead and walk straight past genre. It takes supervision to pull out a signal that weak.

Which genres are recoverable tells us what the signal actually consists of. Rap is found 80% of the time and EDM 66%, because each has a measurable fingerprint — speech-like vocals in one case, relentless energy with no acoustic content in the other. Pop, rock and Latin music are found almost never. That is not a failure of the classifier so much as a statement about the categories: pop in particular is defined by commercial position rather than by any sound, and a genre that can absorb anything popular cannot have an audio signature. The model is telling us which genre labels describe music and which describe marketing.

On the central question of the project, the answer is unambiguous and worth stating bluntly. The model never predicted a single hit. Its 86.8% accuracy came entirely from saying "no" 5,164 times in a row, which is exactly what a model should do when the features carry no usable signal about the outcome and one answer is far more common than the other. Guessing the majority is the rational strategy when you know nothing, and Naïve Bayes arrived at it. The ten audible qualities of a recording, on this evidence, contain essentially nothing about whether that recording will chart.

There is a lesson here about evaluation that is worth carrying into the remaining modules. An 86.8% accuracy looks like a strong result and is in fact a complete failure, while a 44.2% accuracy looks poor and represents real learning. The difference only becomes visible when accuracy is read against a baseline and when the confusion matrix is inspected rather than summarised. Every supervised method that follows will be reported the same way, because on an outcome this imbalanced a headline accuracy figure can conceal a model that has learned nothing whatsoever.
