XGBoost

Overview

XGBoost is a particular implementation of gradient boosting that adds explicit penalties for complexity, handles missing values natively, and is built to run fast on large datasets. It has become the standard reference point for structured, tabular problems like this one.

It serves as the ceiling test for this project. If a heavily tuned XGBoost model cannot predict song success much better than logistic regression, that is strong evidence the limit lies in the data rather than the method, which is the central claim this whole project is set up to examine.
