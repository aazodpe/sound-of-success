DecTrees

Overview

A decision tree splits the data one question at a time — is the song louder than this, faster than that — until each branch ends in a reasonably pure group. The result is a model anyone can read straight off the page.

That readability is the point. A tree that predicts whether a song charts will show, in plain sequence, which qualities it checked first. Comparing the tree's top splits against the correlations found during exploration is a direct test of whether the obvious signals are the ones that actually matter.
