GradientBoosting

Overview

Gradient boosting also builds its models in sequence, but instead of re-weighting awkward cases it fits each new model to the error left over by the ones before it. Every round is an attempt to correct the current running total by a small, controlled amount.

That controlled correction is what makes it worth comparing against a single decision tree on the same data. If a long sequence of small corrections finds structure that one tree misses, the signal in song success is subtle and additive rather than carved along a few obvious thresholds.
