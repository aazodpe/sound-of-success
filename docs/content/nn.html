NN

Overview

A neural network stacks many simple units into layers, letting later layers build on combinations the earlier ones found. Given enough data, it can capture interactions that no one specified in advance.

A neural network is the most flexible model in this project and therefore the fairest test of a specific question: does song success have structure that the simpler models are missing? If the network only matches regression and trees, that is itself a finding — it would suggest the audible part of success is genuinely simple, and the rest lies outside the audio.
